Política de Privacidad

Última actualización: 17 de julio de 2026

En Cloud Scale respetamos la privacidad de quienes visitan este sitio y de quienes comparten información para solicitar una auditoría o conversación comercial.

1. Responsable

El responsable del tratamiento de los datos recibidos por este sitio es Cloud Scale. Las consultas se gestionan mediante el formulario de contacto.

2. Datos recopilados

Podemos recopilar nombre, empresa, correo electrónico, contenido del mensaje y cualquier información compartida voluntariamente sobre campañas, tracking, ad networks o procesos publicitarios.

3. Finalidades

  • Responder solicitudes de información o auditoría.
  • Coordinar reuniones comerciales.
  • Preparar propuestas sobre performance, medición, server-to-server, compliance o audiencias.
  • Mejorar la experiencia y comunicación del sitio.

4. Base legal

La base para tratar los datos es el consentimiento otorgado al enviar el formulario y el interés legítimo en atender solicitudes comerciales.

5. Conservación

Los datos se conservarán durante el tiempo necesario para atender la solicitud, mantener la relación comercial o cumplir obligaciones legales.

6. Derechos

Podés solicitar acceso, rectificación, actualización, oposición o supresión de tus datos mediante el formulario de contacto del sitio.

7. Seguridad

Aplicamos medidas razonables para reducir riesgos de acceso no autorizado, pérdida o uso indebido de la información.

8. Cambios

Cloud Scale puede actualizar esta política cuando resulte necesario. La versión vigente estará publicada en esta página.
